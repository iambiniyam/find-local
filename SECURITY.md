# Security

find-local builds a local index of your files. If you find a security issue, please report it privately.

Email: biniyam.gashaw@hotmail.com

Please do not attach private documents to a public issue. A small folder of fake files is enough.

## Scope

Examples of issues worth reporting:

- the web UI serving a file outside the index
- path traversal in the thumbnail endpoint
- the index writing file contents somewhere unexpected
- a crash that exposes local file contents

Search quality issues, such as a missing result, are not security issues. Open a normal issue for those.
